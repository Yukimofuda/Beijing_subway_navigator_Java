# 北京地铁：界面精修与地图身份修正

## 本轮目标与边界

对照上级目录 `2023213649_程嘉华.docx` 的课程需求：快速完成路线选择、准确展示时间/票价/换乘、浏览线路与时刻、提供可操作地图。保留原生 HTML/CSS/JS、原背景图片、站点及工作日/双休日数据、现有 Dijkstra 与彩色线路站点条。本轮不把视觉精修变成数据或路由算法重写。

## 从需求到可见改动

| 旧问题 | 本轮实现 | 对应需求 |
| --- | --- | --- |
| 首页大号标题、统计数字、空白到站卡片争夺注意力 | 北京/地铁复合字标、轨道节点、英文小字与时钟分工；移除独立大数字统计卡片 | 清晰的产品识别，不增加用户阅读成本 |
| 路线输入与地图各自孤立 | 一个工作区内左侧行程、右侧真实 SVG 预览；主操作为查看路线，交换靠近表单标题 | 首页直接完成出行准备，而非入口堆砌 |
| 标题只靠大字号 | 查询、票价、列车时刻、线路站点、车次、日历标题分别采用功能图形、细分隔线及简短功能名 | 保留结构和控件，但建立可辨识页面层级 |
| 选择站点后只提供文本信息 | 地图搜索后按真实标签包围盒定位、描边；选中站点连到路线与导览 | 将地图浏览与行程动作连接 |
| 旧匹配由英文 id 前缀猜中文名 | 对照完整原图字形建立精确元素绑定，取消数字后缀归并和大范围近邻猜测 | 正确显示当前指向的站点，而非附近另一站 |
| 404 元数据被当作 404 地图位置 | 分开展示注册表 404 项、真实图面 402 项，以及明确无原图位置的两项 | 不以凑数掩盖地图数据差异 |

## 地图准确性的验收口径

`data/svg_station_mapping_review.json` 针对原图 SHA-256 锁定每个标签的精确 id/结构选择器与 path 字形指纹。页面加载时先校验图源哈希，避免地图换版后旧位置静默误绑；测试逐项验证字形、唯一绑定及源图外车站隔离。散落的字形在取得全部原始节点引用后才组成可交互标签，不改变原文件。

- 404 个注册表记录全部审查：402 个确有原图标签；南八里庄、红庙缺少原图位置，未造点。
- 15 个图源有、站点总表没有的标签，如蓟门桥，仅提示当前总表未收录，不把它们绑定到西土城等别的车站。
- 312 是旧算法的中文名计数，不是原 SVG 的容量。旧映射有 83 项错误前景绑定，不能只给未匹配名字补别名。
- `docs/svg_mapping_investigation.md` 保留完整原始证据与来源；未来改图必须重新生成映射证据。
