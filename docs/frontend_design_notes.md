# Frontend Design Notes

## 颜色规范

- 保留现有背景图片与线路色，线路色只用于线路 badge、线路横线、站点轨迹和状态强调。
- 页面主色继续使用 `--brand` 与 `--brand-strong`，避免新增大面积高饱和色块。
- 错误、空状态、运营提示使用轻量边框和浅背景，不覆盖背景图。

## 字号层级

- 页面主标题使用现有 `.title`。
- 卡片说明使用 `.subtitle`。
- 表单 label 保持短文本，避免说明文字挤占输入区域。
- 结果摘要使用短标签 + 粗体数字，保证耗时、票价、换乘次数最先被看到。

## 间距规范

- 表单卡片内部保持 14-18px 垂直间距。
- 按钮组使用 10px gap 和 flex-wrap，移动端不溢出。
- 空状态卡片与结果卡片复用 `.route-path-card` 视觉，减少新增样式。

## 卡片规范

- 主功能区域继续使用 `.card`、`.tool-panel`、`.board-panel`。
- 查询结果使用多个轻卡片分层：摘要、线路与站点、完整路径、每站到站时间。
- 空状态用卡片承载，不让结果区域直接留白。

## 按钮规范

- 主要动作使用 `.btn-primary`。
- 次要动作使用 `.btn-ghost`。
- 当前页导航或当前模式使用 `.is-active` / `.is-selected`，避免新增另一套按钮体系。
- 票价页按钮使用 `.fare-actions` 局部容器，不全局修改 `.btn`。

## 表单规范

- 所有站点选择器统一通过 `TransitData.createStationPicker`。
- focus / click 打开菜单时显示全集；input 输入时才过滤。
- 点击线路只改变候选范围，不自动写入站点。
- 点击站点才写入 input 和 `dataset.station`。

## 线路色使用规范

- query.html 的路线结果必须保留线路颜色横线和沿途站点结构。
- 不用纯文本列表替代 route-line-visual。
- 换乘提示放在对应线路段标题中，不打断站点条。

## 移动端断点建议

- 700px 以下表单改为单列。
- topbar 允许换行，避免按钮横向溢出。
- 长表格优先使用容器横向滚动，避免强行压缩列宽。
